# Animation specification

The envelope follows `idle → opening → revealing-card → card-visible → transitioning → completed`. One awaited Motion timeline releases the centered wax seal, rotates the flap backwards, raises the opaque framed paper from inside the pocket, holds it for reading, then reveals the photographic page. The timeline's own playhead drives state changes; no timeouts or measurements of moving elements are used. The seal, paper, folds and flap have distinct layers. After opening, the flap moves behind the card. Paper travel is 88% of its own responsive height; the scene reserves the required space above it before playback, including on short landscape screens.

The native modal dialog provides browser focus containment. Opening locks body scrolling and remembers its previous overflow setting. Enter and Space activate the semantic envelope button; Escape and the persistent Skip introduction button complete immediately. A synchronous ref rejects repeated activations, including two clicks in one render frame. Reduced motion bypasses the sequence. Every completion, including replay, Skip, Escape and reduced motion, instantly scrolls to the hero, updates the fragment to #home and focuses its heading. Every full page load presents the envelope; completion is not persisted between reloads. Skip, failure and unmount stop the one tracked timeline and invalidate its generation, so late completion callbacks cannot close a subsequent replay. Replay clears animated inline styles and restores the initial paper geometry. Without JavaScript the dialog stays closed and the invitation remains available.

The opening user event calls the shared music request synchronously before any animation, await or reduced-motion bypass. Skip, mount and session restoration never request playback. The persistent music player owns the actual audio element, play promise, error state and playback events.

A limited CSS falling-hearts layer sits behind the envelope content and throughout the page. The envelope hearts are 1.6 times the page heart size. It ignores pointer events and is disabled for reduced motion. Section reveals use restrained shared easing and an IntersectionObserver; reduced motion shows content immediately.

The photo gallery uses a native dialog with focus restoration, Escape/backdrop close, keyboard navigation and touch swipes. RSVP is one continuous form; conditional questions appear directly beneath the triggering answer, without changing screens or discarding retained answers.
